# 宇和島市の防災データ調査メモ

確認日: 2026-11-05

このメモは、DISASTER SCOPEの初期対象である宇和島市について、公式ページ上で確認できたデータの所在・範囲を記録するものです。ページに掲載されていることと、3Dアプリで利用可能な機械可読データ（GeoJSON等）が得られることは同義ではありません。利用前に元ファイルの内容・座標系・属性・ライセンスを確認します。

## 1. 指定緊急避難場所一覧CSV

- 提供者: 宇和島市（所管課: 危機管理課）
- データ名: 指定緊急避難場所一覧.csv
- 形式・掲載ファイルサイズ: CSV / 21 KB
- ページ更新日: 2024-04-01
- ライセンス表示: CC BY 4.0
- 公式説明ページ: https://www.city.uwajima.ehime.jp/site/opendata-catalog/evacuation-space.html
- 直接ダウンロード: https://www.city.uwajima.ehime.jp/uploaded/library/382035_evacuation_space.csv
- 愛媛県オープンデータカタログ: https://www.pref.ehime.jp/opendata-catalog/dataset/2981.html

### アプリへの取込方法

1. 公式ページからCSVを取得する。
2. 地理データ管理画面でCSVを選択する。
3. ヘッダー名と先頭行を確認し、経度・緯度の列を利用者が選択する。
4. 元データの仕様で座標系がWGS84 / OGC:CRS84（経度・緯度）であることを確認してから、変換を実行する。
5. 変換された点の件数と除外行数を確認し、出典・ライセンス情報を保存する。

**重要:** CSVの各列名・実際の座標値・CRSは、この調査ではファイル本文を取得して検証できていません。列名を推測して取り込んだり、座標をWGS84と決めつけたりしないこと。画面の列選択とCRS確認はそのために設けています。

指定緊急避難場所は緊急時に危険から逃れるための場所であり、指定避難所（避難生活を送る施設）と同一ではありません。災害種別ごとの対応属性を確認せずに、洪水に対応する施設であると表示してはいけません。

## 2. 雨水出水浸水想定区域図

- 提供者: 宇和島市（下水道課）
- 公式説明ページ: https://www.city.uwajima.ehime.jp/site/gesuido/usuishusshui.html
- ページ更新日: 2026-08-27
- ページ記載の対象: 公共下水道事業計画区域内で大雨が降った場合に浸水が予想される区域

これは内水（雨水出水）に関する情報であり、河川洪水や津波の想定区域と混同してはいけません。また、市域全体をカバーすると断定しないこと。図面の入手形式、地理参照情報、区域の属性・深さ、作成条件、利用規約は、図面本体と関連資料を取得して確認する必要があります。

現段階では公式説明ページへの参照リンクのみを用意し、3Dハザードレイヤとしては取り込んでいません。

## 3. 国土地理院の標高タイル

- 公式タイル一覧: https://maps.gsi.go.jp/development/ichiran.html
- DEM5A/5B/5C、DEM10B等のPNG形式タイルとテキスト形式が公開されています。
- 国土地理院はテキスト形式の標高タイルについて、2024年10月から更新を停止した旨を案内しています。

利用時は対象ズームレベルでの提供範囲、データソース、標高値の仕様、出典表示・利用条件を確認します。JPEG/PNG画像タイルを標高値として扱う場合は、公式仕様に従って復号し、単なるRGB色値として扱わないこと。現状のアプリではDEMタイル取得・標高復号・地形ドレープは未実装です。

## 4. 国土数値情報の洪水浸水想定区域

- 公式カタログ: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A31a-2025.html

カタログの存在だけで宇和島市内の特定河川・対象区域のデータ収録を証明したことにはなりません。対象の配布ファイルを取得し、河川名・対象範囲・想定規模・作成時点・CRS・属性定義を確認したあとに限り実データレイヤとして追加します。

## 5. 実装ルール

- 公式データ、仮想データ、推定データを別の区分として管理する。
- 取得日・更新日・出典・CRS・加工履歴・ライセンスを保存する。
- データが未確認・未取得の場合は、実データとして描画しない。
- 指定緊急避難場所と指定避難所、河川洪水と内水氾濫を明確に区別する。
- アプリの表示を、実際の災害時の避難判断や安全保証に用いないよう注意を表示する。
