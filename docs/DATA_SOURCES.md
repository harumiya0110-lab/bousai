# データソースと利用上の注意

調査日: 2026-11-04

## データ区分

- **A: 公的実データ** — 提供機関・対象範囲・取得日・CRS・利用条件を確認し、原データと変換履歴を記録したもの。
- **B: 仮想シミュレーションデータ** — 教育用の仮想表示。現実の地形・浸水・施設を表すものではありません。
- **C: 推定・補助データ** — 推定手法と仮定を明示して表示するもの。

現時点でこのリポジトリには公的な地域データは収録されていません。デモ用の図形・地形を宇和島市の実測情報として扱いません。

## 実装・利用ポリシー

1. 認証を要するデータは、ユーザー認証情報をコミットせず、利用者が取得したデータをローカル処理する方法を優先します。
2. データごとに出典URL、提供者、取得・更新日、CRS、対象範囲、加工の有無、ライセンス/利用条件を記録します。
3. JGD2011、JGD2024、WGS84等のCRSをファイル仕様またはメタデータで確認し、推測による変換を行いません。
4. 浸水想定区域は想定条件下の静的な区域であり、実際の到達時刻・水位・避難安全性の予測として表示しません。
5. デモデータは画面上でも「DEMO DATA」「仮想データ」と表示します。公的データを取得・検証した後にのみ、対応するレイヤを実データ扱いにします。
6. 各提供元の利用規約・ライセンス・測量法上の申請要否を取得・公開前に再確認します。

## GeoJSON手動インポート

データ管理画面では、利用者が取得済みのGeoJSONをブラウザー内へ読み込めます。自動収集・自動ダウンロードではありません。

### 対応条件

- RFC7946互換のOGC:CRS84 / WGS84（経度・緯度）のGeoJSONを想定します。
- GeoJSONに明示CRSがある場合は、EPSG:4326またはCRS84と明確に判断できる宣言のみ受け付けます。その他のCRSは再投影が必要です。
- JGD2011、JGD2024、平面直角座標系等のデータは、元ファイルの仕様を確認し、GISソフト等でWGS84へ正しく再投影してから読み込んでください。
- GeoJSONの構文、ジオメトリ形式、緯度経度の範囲、データ量を検査します。値の正確性、提供元、更新日、ライセンスの正当性までは検証しません。
- 登録データはIndexedDBに保存され、アプリのサーバーへ送信されません。各ファイル20MB、合計100MBが上限です。ブラウザー・端末間で同期されません。

### 3D表示上の制約

登録データは対象範囲のアスペクト比を保った相対縮尺の平面へ投影します。緯度による経度方向の縮みは近似補正しますが、測量用の投影・縮尺ではありません。標高データによる地形ドレープは未実装です。表示上限により、プレビューでは一部の地物・頂点を省略することがあります。元GeoJSONは保存・エクスポートできます。


## 宇和島市の初期対象データ（2026-11-05確認）

宇和島市の公式オープンデータカタログでは「指定緊急避難場所一覧.csv」が掲載され、CSV形式、21KB、ページ更新日2024-04-01、CC BY 4.0、所管課は危機管理課と表示されています。公式ページとファイルリンクは \`docs/UWAJIMA_DATASETS.md\` に記載しています。CSV本文の列名・座標系はまだ検証できていないため、アプリで列を選択し、座標系を確認してからポイントGeoJSONに変換してください。

宇和島市は2026-08-27更新の「雨水出水浸水想定区域について」ページで、公共下水道事業計画区域内において大雨時に浸水が予想される区域図を公表していると説明しています。これは内水・雨水出水の情報であり、河川洪水や津波とは別の災害種別です。図面の機械可読形式・CRS・範囲・属性・利用条件は未確認のため、現時点では3Dハザードレイヤに接続していません。
