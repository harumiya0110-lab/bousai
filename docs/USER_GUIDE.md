# ユーザーガイド（開発プレビュー）

## はじめに

ホームの「3Dシミュレーションを開く」から仮想空間を操作します。初期状態ではDEMO DATAを表示し、宇和島市の実測データを含みません。GeoJSONを登録して3Dレイヤを有効にした場合は、IMPORTED GEOJSON表示へ切り替わります。

## 3D操作

- 左ドラッグ / タッチ: 視点を回転
- 右ドラッグ: 視点をパン
- マウスホイール / ピンチ: ズーム（カメラ距離は制限されています）
- 「ホーム」「斜め」「水平」: カメラ視点の切替
- 左側のチェック: 仮想レイヤまたはインポートレイヤの表示切替
- 地形・建物・マーカーのクリック: 仮想データの詳細を確認

画面下のタイムラインは教育用仮想洪水表示の段階を操作します。実際の水理計算や浸水到達時刻を表すものではありません。

## 仮想施設の実験

1. 「施設を配置」を選択します。
2. 3D地形上をクリックして、仮想・未設置の防災拠点を追加します。
3. 施設を選択し、「移動」を押した後、新しい位置をクリックします。
4. 「削除」で選択中の仮想施設を取り除きます。
5. 「実験を保存」でこのブラウザーのローカルストレージに記録します。
6. 「レポート」画面から保存済みの仮想配置をJSONとして出力できます。

容量、避難効果、実在施設との距離、災害リスクは評価していません。ブラウザーのサイトデータを削除すると保存内容も失われます。

## 地理データ管理（GeoJSON）

1. 上部ナビゲーションまたはホームの「地理データ管理」を開きます。
2. .geojsonまたは.jsonファイルをドロップ、またはファイル選択します。
3. 構造検証の結果、地物数、座標数、座標範囲を確認します。
4. レイヤ名と分類を入力し、提供元・出典URL・データ更新日・利用条件を登録します。
5. 利用規約・出典表示・加工条件を確認した場合のみ確認チェックを付けて保存します。
6. 3Dシミュレーションへ移動し、左側の「読み込んだGeoJSON」欄で、表示したいレイヤごとにチェックを入れます。
7. GeoJSONレイヤ表示中は仮想デモ地形を隠し、読み込んだ地物を相対縮尺の平面として表示します。

### 重要

OGC:CRS84 / WGS84（経度・緯度）以外の座標系は自動変換しません。JGD2011・JGD2024等のファイルは、GISソフトで仕様を確認し、WGS84へ再投影してから読み込んでください。

3Dプレビューは全地物を必ず描画するものではありません。大きなデータは描画数・頂点数を制限します。データ管理画面から元のGeoJSONをエクスポートできます。

登録データはこのブラウザーのIndexedDBに保存されます。各ファイル20MB・合計100MBが上限です。別端末への同期やサーバー保存は行いません。実データの出典・利用条件は利用者が必ず確認してください。

## 未実装の画面

避難分析とデータ分析は、対象地域の検証済みデータがないため機能を提供せず、状態を説明しています。実際の道路経路・避難時間・統計情報として見える値は表示しません。


## CSVから避難場所などのポイントを取り込む

1. 宇和島市の公式ページから「指定緊急避難場所一覧.csv」を取得します。公式ページには2024年4月1日更新、CC BY 4.0と記載されています。最新版がないか、利用前に必ず公式ページで確認してください。
2. 地理データ管理画面でCSVを選択します。
3. CSVのヘッダーと先頭行を確認し、経度列と緯度列を選択します。
4. 元データの仕様を確認し、座標がWGS84 / OGC:CRS84の経度・緯度であることを確認した場合のみチェックを入れます。
5. 「ポイントGeoJSONへ変換してプレビュー」を押します。
6. 変換されたポイント数と、座標が欠損・範囲外のため除外された行数を確認します。
7. 出典、更新日、ライセンスを確認してレイヤを登録します。

CSV取込は、元データの全行を保持するものではなく、有効な座標を持つ行をポイントGeoJSONへ変換します。元のCSVは別途保管してください。CSVの列名だけでは座標系を判定できません。経度・緯度以外の座標列や投影座標を選択しないでください。

宇和島市の指定緊急避難場所一覧・指定避難場所一覧・津波避難ビル一覧は別々のデータです。いずれもCSVを取り込めますが、施設区分の名称・属性を残し、津波避難ビルを河川洪水や内水氾濫の対応施設として表示しないでください。
